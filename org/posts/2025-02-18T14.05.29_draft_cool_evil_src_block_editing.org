#+title:draft cool evil src block editing
#+author:Luis Henriquez-Perez

I thought it would be cool for an edit source code buffer to popup if I enter
insert mode in a code block.  Let's see how to do it.

This should not be an expensive hook but I still do not want it slowing down
insert-mode in non-org buffers, so I would prefer it to be a local hook.

One of the first questions is how to determine if we are in a source block: [[][Forg-in-src-block-p]].

In terms of my configuration this should go in [[][C990-config-evil]].  I am not
a great fan of the boilerplate.  I get the feeling that there should be a better
syntax for adding "nested" hooks like this.  But I need to figure out how to
do it well.

#+begin_src emacs-lisp
(defun oo--enter-src-block-maybe ()
  "Enter source block if point is in source block."
  (when (org-in-src-block-p)
    (org-edit-src-code)))

(defun oo--enable-evil-insert-auto-src-edit ()
  (interactive)
  (add-hook 'evil-insert-state-entry-hook #'oo--enter-src-block-maybe nil t))

(add-hook 'org-mode-hook #'oo-enable-evil-insert-auto-src-edit)
#+end_src
 
It works.  But I realized there are a few rough edges I need to take care of.
