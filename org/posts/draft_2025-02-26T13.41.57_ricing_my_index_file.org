#+TITLE: ricing my index file
#+AUTHOR: Luis Henriquez-Perez

The default index file generated by the sitemap of =org-publish= is not pretty.
It simply lists basic.  And something needs to be done about it.  For help I
looked at a model blog in org-mode, [[https://taingram.org/contact.html][Thomas Ingram]] webiste [[https://taingram.org/][taingram.org]].  It is
not the flashiest and I do want to make my website look good in a minimalistic
sort of way but it looks fine.  It is a good basepoint for me.

Fortunately, Mr.Ingram is an advocate of free software and has his source code
available on his webpage.  I cloned it to find out how he got his index page the
way it is.  Part of the key lies in the first element of his.

#+begin_src emacs-lisp
(setq org-publish-project-alist
      `(("index"
         :base-directory ,taingram--base-directory
         :base-extension "org"
         :exclude ".*"
         :include ("index.org")
         :publishing-directory ,taingram--publish-directory
         :publishing-function org-html-publish-to-html

         :with-title nil
         :html-head     ,taingram--head
         :html-preamble ,taingram--preamble
         :html-postamble ,(taingram--gen-footer))
        ...))
#+end_src
