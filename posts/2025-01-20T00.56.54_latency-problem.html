Diagnosing a Latency Problem

Recently I started experiencing latency in emacs. I could tell the typing and the cursor movement felt slower. And interestingly the problem seemed to worsen over time. At first I thought it was my mode line but enabling and renabling it had no effect. Then I considered whether it was some mode I had enabled. But I did not have any strange modes. I did not even have the usual suspect, text completion, enabled–other than abbrev-mode that is. Suddenly, it hit me: the log buffer. A while back I started logging all sorts of events in my config with lgr. Initially, I intended it to be only while oo-debug-p was active. The plan had been to enable it all the time just until I was sure it worked and make it so it would only be when oo-debug-p was active. Later I thought it was not really costing me anything to leave the log on and I just left it on all the time. The way the logging was set up it wrote to a buffer named *log*. It is only now that I realize that the log buffer unlike the *Message* buffer has no cap. It would just grow larger and larger. At some point it would get so large and be consuming so much of emacs's memory that it would slow everything down. For now, I am disabling logging when oo-debug-p is false. 

(defmacro info! (msg &rest meta)
  (when oo-debug-p
    `(lgr-info oo-logger ,msg ,@meta)))

(defmacro error! (msg &rest meta)
  (when oo-debug-p
    `(lgr-error oo-error-logger ,msg ,@meta)))

(defmacro warn! (msg &rest meta)
  (when oo-debug-p
    `(lgr-warn oo-logger ,msg ,@meta)))

(defmacro fatal! (msg &rest meta)
  (when oo-debug-p
    `(lgr-fatal oo-logger ,msg ,@meta)))

(defmacro trace! (msg &rest meta)
  (when oo-debug-p
    `(lgr-trace oo-logger ,msg ,@meta)))

(defmacro debug! (msg &rest meta)
  (when oo-debug-p
    `(lgr-debug oo-logger ,msg ,@meta)))

Despite than this performance hiccup, logging has been so useful for me that I would like to make it toggleable. Instead of this "band-aid" solution I would like store the logs internally list and with some cap. With this list I can then write the logs to a buffer when I want to see it.
